Module 06 — Causal Inference in Health Research

DAGs, Confounding & Identification

Learning objectives - Distinguish association from causation with clinical examples - Draw and interpret Directed Acyclic Graphs (DAGs) - Identify confounders, mediators, colliders using graph structure - Apply the backdoor criterion to find valid adjustment sets - Simulate confounded data and quantify bias with vs without adjustment

2. Association vs Causation

Potential Outcomes Framework (Rubin, 1974): - Y(1) = outcome if treated | Y(0) = outcome if untreated - Individual causal effect = Y(1) - Y(0) — never directly observed (fundamental problem) - ATE = E[Y(1) - Y(0)] = E[Y(1)] - E[Y(0)]

Key structural variable types:

Type DAG pattern Action
Confounder C → T and C → Y Must adjust
Mediator T → M → Y Do NOT adjust (blocks causal path)
Collider T → C ← Y Do NOT adjust (opens spurious path)
Instrument Z → T, Z ⊥ Y given T Use for IV estimation

4. Collider Bias Demonstration

# Among hospitalised patients: smoking & alcohol appear correlated
# In truth they are independent — conditioning on hospitalisation (collider) opens bias
set.seed(7)
N_col <- 3000
smoking_c  <- rnorm(N_col)
alcohol_c  <- rnorm(N_col)   # truly independent of smoking
hosp_score <- 0.6 * smoking_c + 0.6 * alcohol_c + rnorm(N_col, 0, 0.5)
hospitalised <- as.integer(hosp_score > quantile(hosp_score, 0.75))

r_all  <- cor(smoking_c, alcohol_c)
r_hosp <- cor(smoking_c[hospitalised == 1], alcohol_c[hospitalised == 1])

df_col <- tibble(
  smoking_c    = smoking_c,
  alcohol_c    = alcohol_c,
  hospitalised = hospitalised
)

make_collider_scatter <- function(dat, title, colour) {
  ggplot(dat, aes(x = smoking_c, y = alcohol_c)) +
    geom_point(alpha = 0.3, size = 1.2, colour = colour) +
    geom_smooth(method = "lm", se = FALSE, colour = "black", linewidth = 1) +
    labs(x = "Smoking (latent)", y = "Alcohol (latent)", title = title)
}

p_all <- make_collider_scatter(
  df_col,
  sprintf("Full population r=%.3f", r_all),
  col_blue
)
p_hosp <- make_collider_scatter(
  df_col |> filter(hospitalised == 1),
  sprintf("Hospitalised only r=%.3f", r_hosp),
  col_red
)

p_collider <- (p_all | p_hosp) +
  plot_annotation(
    title = "Collider Bias: Conditioning on hospitalisation\n(a collider) creates spurious smoking-alcohol correlation"
  )

5. Backdoor Criterion & Adjustment Sets

# Formal backdoor criterion check
backdoor_ok <- function(treatment_parents, adjustment_set, treatment_descendants) {
  # Rule 1: No descendant of treatment in adjustment set
  for (v in adjustment_set) {
    if (v %in% treatment_descendants) {
      return(list(ok = FALSE,
                  msg = paste(v, "is a descendant of treatment — blocks causal path!")))
    }
  }
  # Rule 2: All confounders (parents of treatment) blocked
  unblocked <- treatment_parents[!treatment_parents %in% adjustment_set]
  if (length(unblocked) > 0) {
    return(list(ok = FALSE,
                msg = paste("Open backdoor path via:", paste(unblocked, collapse = ", "))))
  }
  list(ok = TRUE, msg = "Adjustment set is valid (all backdoor paths blocked)")
}

# In our DAG: parents of Statin = Age, LDL, CHD, SES (direct confounders)
# Descendants of Statin = MI (outcome only, no mediators explicitly modelled here)
treatment_parents <- c("LDL", "CHD", "Age", "SES")  # from DAG
treatment_desc    <- c("MI")

tests <- list(
  "Empty set"                         = character(0),

  "Smoking, CHD, LDL, Age, SES"       = c("Smoking", "CHD", "LDL", "Age", "SES")

6. Knowledge Check

  1. In the statin DAG, LDL appears as both a confounder AND a mediator. How do you handle this?
  2. A researcher adjusts for post-diagnosis employment status when studying chemotherapy’s effect on survival. What type of bias does this introduce?
  3. SES is a confounder of statin use. But SES is not measured in most EHR datasets. What is this problem called, and how might you address it?
  4. Draw a DAG for the question: “Does exercise reduce depression?” Include BMI, social support, sleep quality, and medication use.
  5. Show algebraically why E[Y|X=1] - E[Y|X=0] ≠ E[Y(1)] - E[Y(0)] when there is unmeasured confounding.
# Exercise 5 — decompose association vs causal effect numerically
# True ATE

# What we observe: E[Y|statin=1] - E[Y|statin=0]  (association, not causation)

  group_by(statin) |>
  summarise(mi_rate = mean(mi), .groups = "drop") |>
