Module 03 — Survival Analysis (Kaplan-Meier & Log-Rank)

Survival Analysis (Kaplan-Meier & Log-Rank)

Learning objectives - Understand censoring and the survival analysis framework - Estimate and plot Kaplan-Meier survival curves with confidence bands - Compare survival curves with the log-rank test and Wilcoxon test - Compute and interpret median survival time and restricted mean survival - Stratify survival by clinical subgroups and annotate at-risk tables

Estimated time: 2 hours | Level: Intermediate | Libraries: survival, survminer, dplyr, ggplot2, broom

# ── Synthetic survival dataset: time to 30-day readmission ───────────────────
set.seed(42)
N <- 1500
base <- matrix(rnorm(N * 3), ncol = 3)

set.seed(99)
diabetes      <- rbinom(N, 1, logistic(0.6 * base[, 1] - 0.5))
heart_failure <- rbinom(N, 1, logistic(0.4 * base[, 2] - 1.2))
copd          <- rbinom(N, 1, logistic(0.5 * base[, 3] - 1.0))
payers        <- sample(
  c("Medicare", "Medicaid", "Private", "Self-pay"),
  N, replace = TRUE, prob = c(0.42, 0.22, 0.28, 0.08)
)
ages     <- as.integer(pmin(pmax(rnorm(N, 62, 16), 18), 95))
sexes    <- sample(c("M", "F"), N, replace = TRUE, prob = c(0.48, 0.52))
los_days <- as.integer(pmin(pmax(rgamma(N, shape = 2.5, scale = 1.8), 1), 30))

# Time to readmission (days after discharge, max follow-up = 365)
# Shorter time for patients with HF, diabetes, high LOS
hazard <- exp(-3.5 + 0.5 * heart_failure + 0.3 * diabetes + 0.15 * (los_days > 7) + 0.2 * copd)
time_to_event <- as.integer(pmin(pmax(rexp(N, rate = hazard), 1), 365))

# Censoring: some patients lost to follow-up before 365 days (30% censored)
censor_time <- as.integer(round(runif(N, 30, 365)))
observed    <- as.integer(time_to_event <= censor_time)   # 1 = event observed
duration    <- ifelse(observed == 1, time_to_event, censor_time)

df <- tibble(
  patient_id      = sprintf("PT-%05d", seq_len(N)),
  age             = ages,
  sex             = sexes,
  payer           = payers,
  los_days        = los_days,
  diabetes        = diabetes,
  heart_failure   = heart_failure,
  copd            = copd,
  duration_days   = duration,
  event_observed  = observed
) |>
  mutate(
    age_group = cut(age, breaks = c(17, 44, 64, 74, 95),
                    labels = c("18-44", "45-64", "65-74", "75+")),
    high_risk = as.integer(heart_failure == 1 | diabetes == 1)
  )

2. The Censoring Concept

Censoring occurs when the event has not yet happened by the end of follow-up, or when a patient is lost. The censored observation still contributes information: we know the patient was event-free up to their last contact.

Censoring type Meaning Example
Right-censored Event not yet occurred at study end Patient still alive at end of follow-up
Left-censored Event occurred before first observation Readmission before first clinic visit
Interval-censored Event occurred between two observations Only know readmission was between visits

In most clinical registry analyses, right-censoring is the norm.

# Restricted mean survival time (RMST) up to t* = 180 days
rmst_from_survfit <- function(fit, t_max = 180) {
  sm <- summary(fit, times = seq(0, t_max, by = 1), extend = TRUE)
  times <- sm$time
  surv  <- sm$surv
  if (min(times) > 0) {
    times <- c(0, times)
    surv  <- c(1, surv)
  }
  if (max(times) < t_max) {
    times <- c(times, t_max)
    surv  <- c(surv, tail(surv, 1))
  }
  sum(diff(times) * head(surv, -1))
}

fit_hf1 <- survfit(Surv(duration_days, event_observed) ~ 1, data = df |> filter(heart_failure == 1))
fit_hf0 <- survfit(Surv(duration_days, event_observed) ~ 1, data = df |> filter(heart_failure == 0))
rmst_hf1 <- rmst_from_survfit(fit_hf1, 180)
rmst_hf0 <- rmst_from_survfit(fit_hf0, 180)

7. Interpreting Crossing Survival Curves

# Simulate crossing curves — when log-rank may be misleading
set.seed(33)
n_cross <- 500
# Group A: early-risk high, late-risk low
t_A <- pmin(pmax(rexp(n_cross, rate = 1 / 60), 1), 365)
e_A <- rbinom(n_cross, 1, 0.65)
# Group B: early-risk low, late-risk high (crossing pattern)
t_B <- c(
  pmin(pmax(rexp(n_cross / 2, rate = 1 / 200), 1), 180),
  pmin(pmax(rexp(n_cross / 2, rate = 1 / 40), 181), 365)
)
e_B <- rbinom(n_cross, 1, 0.60)

cross_df <- tibble(
  time  = c(t_A, t_B),
  event = c(e_A, e_B),
  group = factor(rep(c("Group A (early risk)", "Group B (late risk)"), each = n_cross))
)
km_cross <- survfit(Surv(time, event) ~ group, data = cross_df)
lr_cross <- survdiff(Surv(time, event) ~ group, data = cross_df)
# Wilcoxon (Breslow / Gehan) weighted log-rank — more power for early differences
wilcox_cross <- survdiff(Surv(time, event) ~ group, data = cross_df, rho = 1)
p_lr <- 1 - pchisq(lr_cross$chisq, 1)
p_w  <- 1 - pchisq(wilcox_cross$chisq, 1)

p_cross <- ggsurvplot(
  km_cross, data = cross_df, conf.int = TRUE,
  palette = c("#DC2626", "#2563EB"),
  xlab = "Days", ylab = "S(t)",
  title = "Crossing survival curves — log-rank test loses power\nConsider Wilcoxon (Breslow) test or weighted log-rank",
  legend.title = "", ggtheme = theme_minimal()
)
p_cross$plot <- p_cross$plot +
  annotate("label", x = Inf, y = 0.18, hjust = 1.05, size = 3.2,
           label = sprintf("Log-rank p = %.4f\nWilcoxon p = %.4f\n(may miss crossing)", p_lr, p_w)) +
  coord_cartesian(ylim = c(0, 1.05))

8. Knowledge Check

  1. A patient who withdraws from the study on day 45 without experiencing the event — how should they be coded (duration, event_observed)?
  2. The log-rank p-value for HF vs no-HF is <0.001. Is this sufficient to conclude HF causes faster readmission? What is missing?
  3. RMST for HF group = 94 days vs no-HF = 131 days. How would you phrase this for a clinical report?
  4. When would you prefer Wilcoxon (Breslow) over the log-rank test?
  5. Replicate the payer analysis restricted to patients aged 65+ only. Does the ranking of median survival times change?
