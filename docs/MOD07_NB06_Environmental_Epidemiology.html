Module 07: Spatial Epidemiology

Environmental Epidemiology

Learning objectives - Interpolate point-source pollution data to area-level estimates (kriging, IDW) - Assess exposure-response relationships with ecological regression - Apply air pollution exposure assessment methods (inverse distance, kriging) - Recover spatial range from an empirical semivariogram of a Gaussian random field - Build environmental justice metrics: environmental burden by demographic group - Address ecological fallacy in spatial health analyses

Geometries: Data/US_COUNTY.shp — county polygons in NAD83 Albers (EPSG:5070)
Estimated time: 3 hours | Level: Advanced
Libraries: sf, gstat, ggplot2, dplyr, patchwork

1. Setup

This section is dedicated to the setup for the environmental epidemiology analysis. It loads sf, gstat, ggplot2, and dplyr, sets visualisation defaults, and establishes a random seed for reproducibility. Spatial and geostatistical parameters (number of sampling points, spatial range, and variance for simulated pollution fields) are defined here.

The workflow is point-referenced (geostatistical simulation over CONUS), as a companion to the areal (county) simulation used elsewhere in Module 07. Sampling locations (air-quality monitors / survey sites) are placed at random points on US land. The PM2.5 signal and an unmeasured spatial confounder are drawn as true Gaussian random fields with an exponential covariance (known range + partial sill); PM2.5 is then observed with a nugget (measurement error). The same PM2.5 → CVD exposure-response is used as in the areal version (TRUE_PM25 = 2.5).

This gives data that (a) yields a recoverable variogram, and (b) exposes measurement-error attenuation of the exposure-response.

# 1000 is safer for tutorial render (Cholesky is N×N). Python used 2000.
N_POINTS   <- 1000
RANGE_PM   <- 200.0    # PM2.5 field: exponential range parameter (km); eff. range ~3x
PSILL_PM   <- 4.0      # PM2.5 field: partial sill (spatial variance -> SD ~2 µg/m³)
NUGGET_SD  <- 1.5      # measurement error SD (µg/m³)
RANGE_RISK <- 350.0    # spatial-confounder field range (km)
TRUE_PM25  <- 2.5      # true exposure-response: 1 µg/m³ -> 2.5 CVD deaths/100k

county_shapes <- st_read("Data/US_COUNTY.shp", quiet = TRUE)
county_shapes$FIPS <- as.integer(county_shapes$FIPS)
# Shannon County SD (46113) was renamed Oglala Lakota (46102)
county_shapes$FIPS[county_shapes$FIPS == 46113] <- 46102

# ----------------------------------------------------------------------
# 1. Sample point locations on US land (inherit county context via join)
#    Area-weighted counties + jitter inside polygons (faster than st_sample
#    on a CONUS union, and faster than 2000-point rejection sampling).
# ----------------------------------------------------------------------
areas <- as.numeric(st_area(county_shapes))
pick <- sample.int(nrow(county_shapes), N_POINTS, replace = TRUE, prob = pmax(areas, 1))

crs_albers <- st_crs(county_shapes)
place_in_poly <- function(geom) {
  cen <- st_coordinates(st_centroid(geom))[1, ]
  bb <- st_bbox(geom)
  sx <- max((bb["xmax"] - bb["xmin"]) / 6, 1)
  sy <- max((bb["ymax"] - bb["ymin"]) / 6, 1)
  for (i in 1:15) {
    xy <- c(cen[1] + rnorm(1, 0, sx), cen[2] + rnorm(1, 0, sy))
    pt <- st_sfc(st_point(xy), crs = crs_albers)
    if (as.logical(st_within(pt, geom, sparse = FALSE))) return(pt[[1]])
  }
  st_centroid(geom)[[1]]
}

pt_geoms <- lapply(pick, function(i) place_in_poly(county_shapes$geometry[i]))
pts <- st_sf(
  tibble(
    point_id = sprintf("P%04d", seq_len(N_POINTS) - 1),
    FIPS     = sprintf("%05d", county_shapes$FIPS[pick]),
    state    = county_shapes$STATE[pick],
    county   = county_shapes$COUNTY[pick]
  ),
  geometry = st_sfc(pt_geoms, crs = st_crs(county_shapes))
)

xy  <- st_coordinates(pts)
ll  <- st_transform(pts, 4326)
lon <- st_coordinates(ll)[, 1]
lat <- st_coordinates(ll)[, 2]
N   <- nrow(pts)

# ----------------------------------------------------------------------
# 2. Gaussian random fields via exponential covariance
#    C(h) = psill * exp(-h / range_km), with h in km from Albers metres
# ----------------------------------------------------------------------
Dkm <- as.matrix(dist(xy)) / 1000

grf <- function(range_km, psill) {
  C <- psill * exp(-Dkm / range_km)
  diag(C) <- diag(C) + 1e-6 * psill
  # R chol() returns upper U with U'U = C; Python cholesky is lower L
  as.numeric(t(chol(C)) %*% rnorm(N))
}

field_pm   <- grf(RANGE_PM,   PSILL_PM)
field_risk <- grf(RANGE_RISK, 1.0)

# ----------------------------------------------------------------------
# 3. PM2.5 (signal + nugget), covariates, spatial confounder
# ----------------------------------------------------------------------
pm25_base <- 8 + 4 * (lon - min(lon)) / (max(lon) - min(lon))   # W->E trend
pm25_true <- pmin(pmax(pm25_base + field_pm, 3), 30)            # latent signal
pm25      <- pmin(pmax(pm25_true + rnorm(N, 0, NUGGET_SD), 3), 30)  # measured

pct_poverty  <- 10 + 8 * rbeta(N, 2, 5) + 3 * sin(lon / 20)
population   <- as.integer(rlnorm(N, 10.5, 1.0))
spatial_risk <- as.numeric(scale(field_risk))                   # unmeasured confounder

# ----------------------------------------------------------------------
# 4. Outcome  (true exposure-response: 1 µg/m³ -> 2.5 CVD deaths/100k)
# ----------------------------------------------------------------------
cvd_rate <- 160 + 1.2 * pct_poverty + TRUE_PM25 * pm25_true +
  10 * spatial_risk + rnorm(N, 0, 10)
expected <- (cvd_rate / 100000) * population * 5
observed <- rpois(N, expected)
smr      <- observed / pmax(expected, 1)

pts$lon <- lon
pts$lat <- lat
pts$x   <- xy[, 1]
pts$y   <- xy[, 2]
pts$pm25_true   <- pm25_true
pts$pm25        <- pm25
pts$pct_poverty <- pct_poverty
pts$population  <- population
pts$spatial_risk <- spatial_risk
pts$cvd_rate    <- cvd_rate
pts$observed    <- observed
pts$expected    <- expected
pts$smr         <- smr

df <- st_drop_geometry(pts)
write_csv(df, file.path(out_dir, "point_sim.csv"))

  N, mean(pm25_true), mean(pm25), sd(pm25), min(pm25), max(pm25), mean(cvd_rate)

  unname(coef(lm.fit(X, cvd_rate))[2])
}

Adjusted, TRUE field  (+pov +spatial) = 2.51

The naive regression of CVD on measured PM2.5 is biased by the unmeasured spatial confounder. Adjusting for poverty and the spatial-risk field recovers the true coefficient when the latent field is used, but the same adjustment on measured PM2.5 is attenuated by the nugget — classical measurement-error (regression dilution) bias.

2. Empirical semivariogram of detrended PM2.5 (recover the injected range)

The empirical semivariogram is a key tool in geostatistics to summarise how similar or dissimilar measurements are as a function of distance, capturing spatial correlation structure in a dataset.

Here, we use the empirical semivariogram to quantify spatial structure in the detrended PM2.5 field — that is, the PM2.5 data with large-scale geographic trends (longitude/latitude) removed. Detrending focuses on the spatial “nugget” and range instead of broad trends.

This method helps us check if our simulated PM2.5 data (with its built-in spatial correlation/range) can have its effective range visually recovered from the observed data using only spatial patterns in the residuals.

The steps include: 1. Fit and remove a trend (regression on longitude/latitude) from the PM2.5 point data. 2. Compute the differences between all pairs of residuals and square them (or use gstat::variogram). 3. Group the squared differences into distance bins — the mean of each bin provides the empirical semivariance (γ) at that distance. 4. Plot semivariance against distance, which typically increases then plateaus; the “range” is the distance where this flattening occurs, revealing up to what scale points are spatially correlated.

In this notebook, you will see a semivariogram plot showing how PM2.5 residual similarity decays with geographic distance, and a vertical dashed line indicating the effective range that was injected into the simulation. This visualisation confirms if the simulated spatial range is recovered empirically.

# Detrend measured PM2.5 on lon/lat, then empirical semivariogram via gstat
pts$resid <- residuals(lm(pm25 ~ lon + lat, data = pts))

v_emp <- variogram(resid ~ 1, pts, cutoff = 1.2e6, width = 8e4)

states <- county_shapes %>%
  group_by(STATE) %>%
  summarise(geometry = st_union(geometry), .groups = "drop")

3. Exposure Assessment: Interpolating Point Data to Areas

Air quality monitors are located at specific points but we need estimates at every sample location (and, in applied work, at county centroids or census tracts).

Methods: | Method | Principle | Smoothness | Use case | |——–|———–|————|———-| | IDW | Weight = 1/distance^p | Moderate | Quick, no model | | Kriging (ordinary) | Geostatistical, uses variogram | Smooth | Optimal linear prediction | | Nearest monitor | Assign to closest monitor | Abrupt | Worst but common | | Land-use regression | Predict from land use covariates | Flexible | Urban studies |

We place 35 monitors on US land. Each monitor reads the latent PM2.5 field (inverse-distance from nearby sample points) plus instrument error, then we interpolate back to all sample locations and compare against the true field.

idw_knn <- function(query_xy, source_xy, values, p = 2, k = 8) {
  k <- min(k, nrow(source_xy))
  nq <- nrow(query_xy)
  out <- numeric(nq)
  for (i in seq_len(nq)) {
    d <- sqrt((source_xy[, 1] - query_xy[i, 1])^2 +
                (source_xy[, 2] - query_xy[i, 2])^2)
    idx <- order(d)[seq_len(k)]
    w <- 1 / (d[idx] + 1e-10)^p
    out[i] <- sum((w / sum(w)) * values[idx])
  }
  out
}

set.seed(13)
N_MONITORS <- 35
mon_pick <- sample.int(nrow(county_shapes), N_MONITORS, replace = TRUE,
                       prob = pmax(as.numeric(st_area(county_shapes)), 1))
mon_geoms <- lapply(mon_pick, function(i) place_in_poly(county_shapes$geometry[i]))
mon <- st_sf(
  tibble(mon_id = seq_len(N_MONITORS)),
  geometry = st_sfc(mon_geoms, crs = st_crs(county_shapes))
)
mon_xy <- st_coordinates(mon)

# Monitors sample the true field (IDW from point support) + instrument error
mon$pm25 <- pmin(pmax(
  idw_knn(mon_xy, xy, pm25_true, p = 2, k = 6) + rnorm(N_MONITORS, 0, 1),
  3), 28)

# Nearest monitor
nn <- st_nearest_feature(pts, mon)
pts$pm25_nearest <- mon$pm25[nn]

# IDW (gstat, p = 2, k = 10)
idw_pred <- gstat::idw(
  pm25 ~ 1, locations = mon, newdata = pts,
  idp = 2, nmax = 10, debug.level = 0
)
pts$pm25_idw <- idw_pred$var1.pred

# Ordinary kriging with exponential model matching the injected range
# (gstat Exp: C(h) = psill * exp(-h/a); a in metres)
vgm_ok <- vgm(psill = PSILL_PM, model = "Exp",
              range = RANGE_PM * 1000, nugget = NUGGET_SD^2)
ok_pred <- krige(
  pm25 ~ 1, mon, newdata = pts, model = vgm_ok,
  debug.level = 0
)
pts$pm25_krige <- pmin(pmax(ok_pred$var1.pred, 3), 30)

df <- st_drop_geometry(pts)

interp_cols <- c(
  pm25_true    = "True PM2.5 field",

vmax <- as.numeric(quantile(df$pm25_true, 0.95))

p_interp <- (

  )
print(p_interp)
ggsave(file.path(out_dir, "pm25_interpolation.png"), p_interp,

for (col in c("pm25_nearest", "pm25_idw", "pm25_krige")) {

Nearest-neighbour assignment is piecewise constant and typically has the highest RMSE. IDW is a fast, parameter-light smoother. Ordinary kriging uses the variogram (here, the exponential model that generated the field) and is the best linear unbiased predictor under that model — provided the variogram is well specified.

4. Exposure-Response Analysis: Ecological Regression

Ecological regression is a way to study relationships between group-level variables — like average air pollution and disease rates.

Imagine you want to see if more polluted places have higher disease rates. For each sample location (standing in for a community), you have: - the average PM2.5 air pollution value - the rate of cardiovascular disease (CVD)

We fit a (linear) model:

CVD_rate = a + b × PM2.5 + c × poverty + random_noise

  • CVD_rate: Disease rate at the location
  • a: The “baseline” rate if pollution and poverty are 0
  • b: How much the disease rate goes up for each step in PM2.5 (the main thing we care about)
  • c: How much poverty affects disease rate

The model tries to find b — the change in CVD rate for each additional µg/m³ of PM2.5 — by drawing a line that best fits all location-level data points.

In plain English: we’re seeing whether more polluted places have more heart disease, after accounting for poverty.

# Ecological regression: CVD rate ~ measured PM2.5 + poverty

5. Environmental Justice Analysis

Environmental justice (EJ) analysis asks: are pollution and other environmental risks shared equally among all groups, or do some (often already disadvantaged) groups bear a greater burden?

In this section, we look at whether PM2.5 exposure is higher in communities with more poverty (and, as a simulated demographic, higher minority share). This helps highlight possible inequities in who is most affected by pollution. We compare pollution levels across poverty tertiles, map the burden, and compute disparity ratios.

6. Ecological Fallacy: Individual vs Aggregate Data

Imagine you want to know if breathing more air pollution (like PM2.5) makes individuals more likely to get heart disease. If you only look at the average air pollution and the average heart disease rates for each community (big groups), you might see a pattern. But this does not always mean that the same trend is true for each person.

The ecological fallacy happens when you take results from group-level data (like counties or cities) and assume they must be true for individuals within those groups. This is risky because group averages can hide what is really happening among individuals. Other factors can mix things up (like richer counties may have less pollution and better healthcare, but within each county, poor people may still be the most at risk).

Key takeaway: just because there is a pattern between pollution and disease at the county level, does not guarantee you will see it (or the same strength) for individual people. Be careful when jumping from group data to conclusions about individuals.

set.seed(7)

band_km <- 200
w <- 1 / Dkm
