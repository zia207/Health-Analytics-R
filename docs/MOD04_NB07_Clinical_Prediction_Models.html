Module 04 — Machine Learning for Clinical Prediction

Three Clinical Prediction Models

Learning objectives - Adapt the ML pipeline for three distinct clinical prediction tasks - Sepsis early warning: high-recall binary classifier with alert threshold - ICU LOS forecasting: regression with GBM + confidence intervals - 30-day readmission scoring: probability-calibrated risk tier model - Compare model architectures, evaluation metrics, and deployment considerations

Estimated time: 3 hours | Level: Advanced | Libraries: tidymodels, xgboost, DALEX, ggplot2

# Patient features
age <- as.integer(clip(rnorm(N, 58, 18), 18, 95))
sex <- sample(c("M", "F"), N, replace = TRUE, prob = c(0.48, 0.52))
diabetes <- rbinom(N, 1, sig(0.6 * b[, 1] - 0.5))
hf <- rbinom(N, 1, sig(0.4 * b[, 2] - 1.2))
copd <- rbinom(N, 1, sig(0.5 * b[, 3] - 1.0))
ckd <- rbinom(N, 1, sig(0.5 * b[, 1] + 0.6 * diabetes - 1.2))
immunocomp <- rbinom(N, 1, sig(0.3 * b[, 5] - 1.5))

# Vital signs
set.seed(21)
temp <- round(clip(rnorm(N, 37.2 + 0.8 * immunocomp, 0.8), 34, 42), 1)
hr   <- round(clip(rnorm(N, 85 + 15 * hf + 10 * immunocomp, 18), 40, 180), 0)
sbp  <- round(clip(rnorm(N, 125 - 10 * ckd, 22), 60, 200), 0)
resp <- round(clip(rnorm(N, 18 + 4 * copd + 2 * immunocomp, 4), 8, 40), 0)
wbc  <- round(clip(rgamma(N, shape = 4 + 3 * immunocomp, scale = 2), 0.5, 40), 1)
lactate <- round(clip(rgamma(N, shape = 1.5 + 2 * immunocomp, scale = 0.8), 0.5, 15), 2)
creatinine <- round(clip(rgamma(N, shape = 1.6 + 0.8 * hf + 0.5 * ckd, scale = 0.6), 0.4, 12), 2)
n_comorb <- diabetes + hf + copd + ckd

# ── OUTCOME 1: Sepsis (high-recall binary) ────────────────────────────────────
sepsis_logit <- (-4.0 + 0.8 * immunocomp + 0.5 * as.integer(temp > 38.5) +
                   0.4 * as.integer(hr > 100) + 0.6 * as.integer(lactate > 2.0) +
                   0.5 * as.integer(wbc > 12) + 0.3 * as.integer(sbp < 90) +
                   0.3 * as.integer(resp > 22) + rnorm(N, 0, 0.3))
sepsis <- rbinom(N, 1, sig(sepsis_logit))

# ── OUTCOME 2: ICU LOS (regression) ──────────────────────────────────────────
icu_los <- round(clip(2.0 + 1.5 * sepsis + 1.2 * hf + 0.8 * ckd + 0.5 * copd +
                        0.04 * (age - 58) + 0.8 * as.integer(lactate > 2) +
                        0.5 * as.integer(sbp < 90) + rgamma(N, shape = 1.5, scale = 1.2),
                      1, 30), 1)

# ── OUTCOME 3: 30-day readmission (calibrated probability) ───────────────────
logit_re <- (-3.2 + 0.6 * hf + 0.5 * diabetes + 0.5 * ckd + 0.3 * copd +
               0.02 * (age - 58) / 15 + 0.3 * as.integer(icu_los > 7) +
               0.5 * hf * diabetes + rnorm(N, 0, 0.25))
readmitted <- rbinom(N, 1, sig(logit_re))

df <- tibble(
  age, sex, diabetes, hf, copd, ckd, immunocomp, n_comorb,
  temp, hr, sbp, resp, wbc, lactate, creatinine,
  sepsis, icu_los, readmitted
)

2. Model 1 — Sepsis Early Warning (High-Recall Classifier)

What does this section do?

This section introduces and explains the first example clinical prediction model: an early warning system for hospital sepsis built to prioritize high sensitivity. The goal is to develop a binary classifier that reliably identifies (predicts) patients who are developing or at risk for sepsis—an acute and potentially fatal medical condition.

Key points explained: - Why high recall?
In clinical workflows, missing a true case of sepsis (false negative) can have severe consequences for the patient. Thus, the model is tuned to maximize recall (sensitivity), meaning it will catch as many cases as possible, even if that produces more false positives (unnecessary alerts). - Features used:
The prediction is based on a combination of demographics, comorbidities, and real-time vital signs (like temperature, heart rate, blood pressure, labs). - Model and technical steps:
The workflow includes data preprocessing, imputation for missing values, normalization, and uses XGBoost for classification. The model’s decision threshold is specifically chosen to achieve at least 90% sensitivity on the validation data, ensuring most sepsis cases trigger an alert. - Metrics:
The explanation covers how AUC (a broad discrimination measure), average precision (helpful in imbalanced settings), and clinical-threshold sensitivity/specificity/PPV are reported. Special attention is given to the practical meaning of sensitivity (recall) for real-world deployment. - Clinical relevance:
The section underscores why such an approach—accepting more false alarms to reduce missed cases—is appropriate in high-stakes settings like sepsis detection. It helps learners appreciate the tradeoffs in applying ML to critical care, preparing them to set model thresholds according to actual clinical priorities and not just statistical optimization.

In summary, this model exemplifies how to align a machine learning classifier to critical clinical goals—here, minimizing missed sepsis by maximizing recall, and understanding the tradeoffs involved.

VITALS <- c("temp", "hr", "sbp", "resp", "wbc", "lactate", "creatinine", "age")
COMORB <- c("diabetes", "hf", "copd", "ckd", "immunocomp", "n_comorb")

3. Model 2 — ICU Length-of-Stay Forecasting (Regression)

This section focuses on building a model to predict the length of stay (LOS) for patients in the Intensive Care Unit (ICU), a numerical outcome best approached as a regression problem. Unlike classification (e.g., sepsis detection), here we estimate a continuous value—how many days a patient is likely to remain in the ICU—using clinical features such as vital signs, comorbidities, and indicators like sepsis.

We train an XGBoost regression model using these features, evaluate its performance with standard regression metrics (MAE, RMSE, R²), and examine the predictions and their errors. Additionally, we estimate approximate prediction intervals to understand the uncertainty of the model’s forecasts.

LOS_FEATURES <- c(VITALS, COMORB, "sepsis")

4. Model 3 — 30-Day Readmission Risk Score (Calibrated)

This section introduces the third clinical prediction model: a 30-day readmission risk score built to provide a calibrated probability estimate for each patient. Unlike the previous models which focused on early warning or forecasting, this model estimates the probability of readmission within 30 days based on clinical features such as demographics, comorbidities, and hospital course (e.g., sepsis, ICU length of stay).

We train an XGBoost classifier with a binary logistic objective, evaluate its performance using AUC (area under the ROC curve) and Brier score (which measures calibration), and perform risk stratification into four tiers based on the predicted probability. Additionally, we apply Platt scaling to calibrate the raw model probabilities, improving their clinical interpretability and reliability.

RE_FEATURES <- c(VITALS, COMORB, "icu_los")
set.seed(42)
df_r <- df %>%
  select(all_of(c(RE_FEATURES, "readmitted"))) %>%
  mutate(readmitted = factor(readmitted, levels = c(0, 1)))
sp_r <- initial_split(df_r, prop = 0.80, strata = readmitted)
Xr_tr_all <- training(sp_r); Xr_te <- testing(sp_r)

Xrtr  <- as.matrix(bake(pre_r, new_data = Xr_tr2) %>% select(-readmitted))

5. Three-Model Deployment Summary

This section summarizes the three clinical prediction models built in previous sections: sepsis early warning, ICU length-of-stay forecasting, and 30-day readmission risk scoring. It provides a comprehensive overview of how these models were developed, evaluated, and deployed in a real-world clinical setting.

Key points explained: - Model 1: Sepsis Early Warning
This model is designed to alert healthcare professionals when a patient is at high risk of developing sepsis, a severe and potentially life-threatening condition. It uses a high-sensitivity threshold to minimize missed cases, even at the cost of increased false alarms. - Model 2: ICU Length-of-Stay Forecasting
This model estimates how many days a patient is likely to remain in the ICU, useful for bed management and resource allocation. It provides a continuous prediction rather than a binary alert. - Model 3: 30-Day Readmission Risk Score
This model estimates the probability of readmission within 30 days, helping identify patients who may benefit from early intervention programs. It uses Platt scaling to improve calibration and risk stratification.

patient_risk_dashboard <- function(patient_row) {
  # Return sepsis alert, expected LOS, readmission tier for one patient.
  Xs <- as.matrix(bake(pre_s, new_data = as_tibble(patient_row[SEPSIS_FEATURES])) %>%
                    select(-any_of("sepsis")))
  Xl <- as.matrix(bake(pre_l, new_data = as_tibble(patient_row[LOS_FEATURES])) %>%
                    select(-any_of("icu_los")))
  Xr <- as.matrix(bake(pre_r, new_data = as_tibble(patient_row[RE_FEATURES])) %>%
                    select(-any_of("readmitted")))
  p_sepsis <- predict(gb_sepsis, Xs)
  p_los    <- predict(gbr, Xl)
  p_re_raw <- predict(gb_re, Xr)
  p_re_cal <- as.numeric(predict(platt, newdata = tibble(p = p_re_raw), type = "response"))
  tier <- dplyr::case_when(
    p_re_cal < 0.10 ~ "Low",
    p_re_cal < 0.20 ~ "Moderate",
    p_re_cal < 0.35 ~ "High",
    TRUE ~ "Very high"
  )
  list(sepsis_alert = p_sepsis >= thr_highsens, sepsis_prob = round(p_sepsis, 3),
       expected_los = round(p_los, 1), readmit_prob = round(p_re_cal, 3),
       readmit_tier = tier)
}
