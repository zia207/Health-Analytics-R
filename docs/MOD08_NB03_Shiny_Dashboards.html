Health Analytics with R · Module 08: Reproducible Research & Deployment

Learning objectives - Build a multi-tab clinical analytics Shiny dashboard - Use bindCache() and reactiveValues() for performance - Create interactive filters, KPI metrics, and downloadable tables - Implement patient risk alerting with adjustable thresholds - Apply authentication and multi-page navigation patterns - Deploy Shiny apps via Docker, shinyapps.io, and Posit Connect

Estimated time: 3 hours | Level: Intermediate | Libraries: shiny, shinydashboard, ggplot2, tidymodels

set.seed(42)
N <- 3000
sigmoid <- function(x) 1 / (1 + exp(-x))
df <- tibble(
  patient_id = sprintf("PT-%05d", seq_len(N) - 1),
  age        = as.integer(pmin(pmax(rnorm(N, 60, 15), 18), 90)),
  sex        = sample(c("M", "F"), N, replace = TRUE, prob = c(0.48, 0.52)),
  payer      = sample(
    c("Medicare", "Medicaid", "Private", "Self-pay"),
    N, replace = TRUE, prob = c(0.40, 0.22, 0.28, 0.10)
  ),
  unit       = sample(c("Cardiology", "Pulmonology", "Medicine", "Surgery"), N, replace = TRUE),
  los_days   = as.integer(pmin(pmax(rgamma(N, 2.5, scale = 1.8), 1), 30)),
  diabetes   = rbinom(N, 1, 0.35),
  hf         = rbinom(N, 1, 0.22),
  copd       = rbinom(N, 1, 0.18)
)
logit <- -3.2 + 0.6 * df$hf + 0.5 * df$diabetes + 0.02 * (df$age - 60) +
  0.2 * as.integer(df$los_days > 7)
df$readmit_prob <- sigmoid(logit)
df$readmitted   <- rbinom(N, 1, df$readmit_prob)
df$admit_date   <- seq(as.POSIXct("2023-01-01"), by = "6 hours", length.out = N)
saveRDS(df, file.path(app_dir, "data", "processed", "features.rds"))
write_csv(df, file.path(app_dir, "data", "processed", "features.csv"))
cat(sprintf("Dashboard dataset: %d x %d | Readmission: %.1f%%\n",
            nrow(df), ncol(df), mean(df$readmitted) * 100))

2. Shiny Architecture for Clinical Dashboards

app.R                    <- Single-file entry point
# or
ui.R + server.R          <- Multi-file Shiny
R/
  model.R                <- load_model(), predict_risk()
  data.R                 <- load_data(), filter_data()
  plots.R                <- reusable ggplot2 helpers

Key Shiny concepts for clinical apps: - bindCache() / reactive(): cache expensive data loads (invalidate on input change) - reactiveValues(): persist user selections across tabs - sidebarPanel(): filters that update all tabs simultaneously - shinydashboard::valueBox() / KPI cards with delta indicators - downloadHandler(): export high-risk patient lists to CSV

# Demonstrate Shiny component patterns without running the server
set.seed(42)
split <- initial_split(df, prop = 0.8, strata = readmitted)
train <- training(split)
test  <- testing(split)
feat <- c("age", "los_days", "diabetes", "hf", "copd")
dtrain <- xgb.DMatrix(as.matrix(train[feat]), label = train$readmitted)
bst <- xgb.train(
  params = list(objective = "binary:logistic", max_depth = 4, eta = 0.05,
                eval_metric = "auc"),
  data = dtrain, nrounds = 200, verbose = 0
)
df$readmit_prob <- predict(bst, as.matrix(df[feat]))
prob_te <- predict(bst, as.matrix(test[feat]))
auc <- as.numeric(pROC::auc(test$readmitted, prob_te, quiet = TRUE))

kpi_data <- tibble(
  label = c("Total Patients", "Readmission Rate", "Mean LOS", "High Risk (>25%)", "Model AUC"),
  value = c(
    format(nrow(df), big.mark = ","),
    sprintf("%.1f%%", mean(df$readmitted) * 100),
    sprintf("%.1f days", mean(df$los_days)),
